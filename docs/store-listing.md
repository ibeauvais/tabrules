## Store listing

**Name:** TabRules

**Summary** (at most 132 characters):

> Group tabs automatically with your own rules: exact hostnames or regular expressions. No network access, no data collection.

**Category:** Productivity → Tools

**Language:** English

**Description:**

> TabRules groups your tabs automatically, following rules you define.
>
> • Exact hostname rules: "github.com" puts every GitHub tab in one group.
> • Regular expression rules: "(^|\.)google\.com$" groups google.com and all its subdomains.
> • A "*" rule groups every other site by hostname.
> • Priority: rules are checked from top to bottom and the first match wins. Reorder them in one click.
> • Choose a title and a color for each group.
> • Groups you create yourself are never touched.
> • Pause grouping at any time from the toolbar.
> • Import and export your rules as a JSON file.
>
> Private by design:
> • Only three permissions: tabs, tab groups and storage.
> • No network access: the extension cannot send anything, enforced by its content security policy.
> • No data collection, no analytics, no third-party code.
> • Your rules stay on your device.
>
> Open source (MIT) and auditable: the code is readable, the release is reproducible, and every build comes with a provenance attestation.
> Source code: https://github.com/ibeauvais/tabrules

## Privacy practices

**Single purpose:**

> Group the user's browser tabs automatically according to rules the user defines.

**Permission justifications:**

| Permission  | Justification                                                                                                                                                                       |
| ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tabs`      | Read the address of each tab to compare its hostname with the user's rules and decide which group it belongs to. Addresses are used in memory only and never stored or transmitted. |
| `tabGroups` | Create tab groups, set their title and color, and add or remove tabs from the groups the extension manages.                                                                         |
| `storage`   | Save the user's rules on the device (`chrome.storage.local`) and remember which groups the extension created during the browser session (`chrome.storage.session`).                 |

**Remote code:** No, I am not using remote code. All code is packaged in the extension, and the content security policy forbids loading anything else.

**Data usage:** check none of the data categories. The extension does not collect or transmit any user data.
